Featured project

Cognitio

An offline desktop app with ten tasks for exploring attention, memory, executive function, and response speed.

I built Cognitio for an expedition where internet access was uncertain. The offline options I found were expensive and proprietary, so I built a tool I could run in the field.

Native speakers helped translate Cognitio into Spanish and Russian.
